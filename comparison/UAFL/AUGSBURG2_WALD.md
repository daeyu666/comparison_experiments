# UAFL — Augsburg-2 strict Wald x3 (real Sentinel-2)

This is a standalone comparison track. It does **not** change
`S2Diff-MH`, `comparison/UAFL/model.py`, or the synthetic Augsburg x4 run.

## Frozen protocol (read from S2Diff-MH, 2026-10-08)

- Supervision: *observed* 30m EnMAP-like HSI, 242 bands.
- LR-HSI input: Wald 90m HSI produced from that observed 30m HSI using
  `prepare_augsburg2_wald.py`, effective Gaussian sigma=1.2 on the 30m grid.
- HR-MSI input for Wald train/test: actual Sentinel-2 10m B2/B3/B4/B8,
  area-aggregated to the 30m grid. No synthetic SRF-generated replacement.
- Factor: x3 (90m -> 30m). MSI is NOT warped or content-registered.
- Real MSI radiometry: the **train-only** four-channel gain/bias stored in
  `data/calibration/Augsburg2_Wald_radiometry.json`; no shift is applied.
- Cache: `data/augsburg2_wald/` generated by S2Diff-MH. Wald metadata must
  contain `msi_source=real_Sentinel_2_Wald_30m`,
  `gt_source=observed_30m_HSI_only`.
- Default cache generation: `--training_area region2` means the 30m
  observations in sub_area_2 can supervise Wald downscaled learning; there
  are **no** 10m reference labels in this run.
- Train tile=72, stride=6; val/test tile=48, strict valid fraction>=0.8.
  Validation/test use the same held-out cache splits and evaluation masks as
  S2Diff-MH. No train spatial augmentation for strict Wald.
- UAFL paper topology unchanged (CFDA/SCACA/SCMF), AdamW 1e-5, wd 5e-5,
  batch1, masked L1, 100 epochs, validation every 5 epochs.
- Best checkpoint selected by *minimum pooled masked validation SAM*, matching
  S2Diff-MH Wald-D2 default `monitor=ref_sam`. `--monitor ref_psnr` is
  available for sensitivity analysis; do not mix monitor settings in a table.
- UAFL needs sizes divisible by 16 internally (8x8 windows before/after
  downsampling). For the externally fixed 72x72 Wald training tile,
  `predict_uafl` temporarily pads only the **network input** to 80x80, then
  crops predictions back to 72x72. The Wald image, data split, labels and
  mask are unchanged. 48x48 val and 96x96 full inference need no padding.

## Preparation

Run the unchanged S2Diff-MH data preparation/calibration to produce:
`data/augsburg2_wald/{train,validation,test,full}/...`,
`data/augsburg2_wald/wald_psf.json`, and
`data/calibration/Augsburg2_Wald_radiometry.json`.
The cache must be available in the **comparison** working tree, either
as a symlink, or supply explicit paths to the original S2Diff-MH cache.
Do not overwrite an existing calibrated cache with an unverified new source.

From the `comparison_experiments` root, with the two repositories
as siblings, e.g.:

```bash
git pull
export WALD_ROOT="../S2Diff-MH/data/augsburg2_wald"
export WALD_RAD="../S2Diff-MH/data/calibration/Augsburg2_Wald_radiometry.json"
test -f "$WALD_ROOT/train/meta.json"
test -f "$WALD_ROOT/wald_psf.json"
test -f "$WALD_RAD"
```

## Train

```bash
python comparison/UAFL/train_augsburg2_wald.py \
  --wald_root "$WALD_ROOT" \
  --radiometry_json "$WALD_RAD" \
  --stage train \
  --train_patch_size 72 --train_stride 6 --eval_patch_size 48 \
  --min_valid_fraction 0.80 --batch_size 1 \
  --lr 1e-5 --weight_decay 5e-5 \
  --epochs 100 --eval_interval 5 --save_interval 5 \
  --monitor ref_sam --seed 10 --device cuda
```

Best: `comparison/UAFL/checkpoints/augsburg2_wald/best.pth.tar`.
Last: `comparison/UAFL/checkpoints/augsburg2_wald/last.pth.tar`.

Resume (epochs is an **absolute** terminal epoch):

```bash
python comparison/UAFL/train_augsburg2_wald.py \
  --wald_root "$WALD_ROOT" --radiometry_json "$WALD_RAD" \
  --epochs 150 --monitor ref_sam \
  --resume comparison/UAFL/checkpoints/augsburg2_wald/last.pth.tar
```

## Held-out Wald x3 test (reference: observed 30m HSI)

```bash
python comparison/UAFL/train_augsburg2_wald.py \
  --stage test --wald_root "$WALD_ROOT" \
  --radiometry_json "$WALD_RAD" \
  --checkpoint comparison/UAFL/checkpoints/augsburg2_wald/best.pth.tar
```

This is the ONLY supervised/reference-based final test in the strict Wald
experiment. PSNR and SAM are pooled over all valid held-out 30m pixels, matching
S2Diff-MH's Wald reference metric definitions.

## Full original-scale inference (30m HSI + real 10m MSI -> 10m HSI)

```bash
python comparison/UAFL/infer_augsburg2_wald.py \
  --wald_root "$WALD_ROOT" --radiometry_json "$WALD_RAD" \
  --checkpoint comparison/UAFL/checkpoints/augsburg2_wald/best.pth.tar \
  --tile_size 96 --tile_stride 48 --write_tif
```

Output: `comparison/UAFL/outputs/augsburg2_wald/Augsburg2_Wald_UAFL_full_HSI.npy`
(and GeoTIFF when requested). Its frame/georeferencing matches the
S2Diff-MH Wald `sub_area_2` original-scale inference grid.

No 10m HR-HSI label is available here. Do not report original-scale
PSNR, SAM or EPE from an invented reference.

### Full-resolution QNR / Dlambda / Ds — classical equations

`infer_augsburg2_wald.py` automatically evaluates and saves
`comparison/UAFL/outputs/augsburg2_wald/UAFL_Wald_full_QNR.json`.
This **replaces** the old 16-cross-band modified-QNR implementation.
Old JSON scores are NOT comparable to the new scores; recompute them.

The implementation uses the **classical QNR equations (Alparone 2008)**:

- `F4=R(F)`: four 10m bands from the fused 242-band HSI, projected through
  the fixed four-band Sentinel-2 SRF `R`.
- `H4=R(H)`: four 30m bands from observed 30m HSI, using the same SRF.
- `P`: one shared 10m PAN image.
- `P_L`: a correspondingly low-pass/downsampled 30m PAN.
- `Dlambda`: mean over **6 unordered band pairs** of
  `|Q(F4_i,F4_j)-Q(H4_i,H4_j)|`.
- `Ds`: mean over **4 matched band-to-PAN comparisons** of
  `|Q(F4_i,P)-Q(H4_i,P_L)|`, not 16 cross-band comparisons.
- `QNR=max(0,1-Dlambda)*max(0,1-Ds)`; exponents `p=q=alpha=beta=1`.
- UIQI uses masked non-overlapping 48x48 high-res / 16x16 low-res windows,
  minimum valid fraction 80%, weighted by valid pixels, and the same
  observed-input masks as S2Diff-MH.

**Augsburg Region 2 has no true PAN sensor observation.** The default `P`
is an *explicit synthetic PAN proxy*: the unweighted arithmetic mean of
four **train-calibrated, unwarped real Sentinel-2 B2/B3/B4/B8** bands.
`P_L` is its 3x3 area average. This is **standard-form QNR using a
pseudo-PAN**, *not classical real-PAN QNR*. The output JSON has
`is_genuine_pan=false` and an explicit `pan_origin`. No original-scale
10m HSI reference is used; 242-band fidelity is not established.

For genuinely PAN-based standard QNR, provide a separate real PAN image and
the sensor-MTF-matched 30m degraded PAN via `--pan_hr` and `--pan_lr`.
Neither is present in the official four-band Augsburg observation dataset.
Single-PAN and pseudo-PAN results must never be pooled in a table without
their source labels.

Score an existing full-resolution UAFL output without rerunning the network:

```bash
python comparison/UAFL/augsburg2_wald_qnr.py \
  --wald_root ./data/augsburg2_wald \
  --fused comparison/UAFL/outputs/augsburg2_wald/Augsburg2_Wald_UAFL_full_HSI.npy \
  --radiometry_json ./data/calibration/Augsburg2_Wald_radiometry.json \
  --output_json comparison/UAFL/outputs/augsburg2_wald/UAFL_Wald_full_QNR.json
```

Optional true PAN:

```bash
# Only when both actual PAN inputs exist on the same geographical grid
python comparison/UAFL/augsburg2_wald_qnr.py \
  --wald_root ./data/augsburg2_wald \
  --fused comparison/UAFL/outputs/augsburg2_wald/Augsburg2_Wald_UAFL_full_HSI.npy \

```

Run regression tests:

```bash
python -m unittest discover -s comparison/UAFL -p "test_augsburg2_wald_qnr.py"
```

For method comparisons, both repositories use the byte-identical QNR
kernel, the same frozen SRF, mask, radiometry and window policy. The
`S2Diff-MH/compare_augsburg2_wald_qnr.py` script now rejects older
modified-QNR JSON and mismatched PAN provenance.

## Important differentiation

This is **not** Augsburg Synthetic x4, Augsburg-Real EnMAP10-supervised x3,
or the old UAFL warp-MSI curriculum. Never load weights from these
experiments as the strict Wald baseline, and never select an epoch by the
full-region original-resolution appearance.
