# UAFL — CVPR 2026 reproduction

Paper: **Enhancing Unregistered Hyperspectral Image Super-Resolution via Unmixing-based Abundance Fusion Learning**, CVPR 2026.

Official implementation: `yingkai-zhang/UAFL`.

This directory contains the UAFL reproduction used by `comparison_experiments`.
It is placed directly under `comparison/UAFL/`, alongside `comparison/EMR-Diff/`.

## Reproduction rule

The comparison implementation follows one strict rule:

> **Keep the UAFL network topology and paper operations unchanged; only adapt the
> high-resolution reference channel count and replace incompatible low-level CUDA
> execution backends with mathematically equivalent current-PyTorch operators.**

The following UAFL components are preserved:

- SVD-based HSI unmixing;
- abundance-map input representation;
- one down/up multi-scale encoder-decoder used by the released architecture;
- Coarse-to-Fine Deformable Aggregation (CFDA);
- the released two-level pyramid prior-flow/similarity predictor;
- sub-pixel sinusoidal positional encoding with 8 frequencies;
- residual DCNv2 offset and modulation-mask prediction;
- `deformable_groups = 8` and `max_residue_magnitude = 10`;
- Spatial-Channel Abundance Cross-Attention (SCACA);
- 8x8 window spatial cross-attention and shifted-window cross-attention;
- the released channel-abundance attention path;
- Spatial-Channel Modulated Fusion (SCMF);
- abundance residual prediction;
- mixing with the SVD endmembers and residual addition to the upsampled LR-HSI.

No RAFT, PWCNet, mmflow, external registration network, or pretrained optical-flow
network is introduced into UAFL. Those files in the official repository belong to
other baselines / earlier comparison code and are not on the UAFL forward path.

## Paper-sized configuration audit

The public `UAFL` class currently exposes the source-code default

```text
dim=28, stage=1, num_blocks=[2,1], numend=3
```

while the same released model hard-codes `deformable_groups=8`. A feature width of
28 is not divisible by 8 and therefore cannot be the actual DCNv2 paper run
configuration. In addition, the paper reports approximately **5.94 M parameters**,
whereas the literal `dim=28` default is far below that model size.

The paper-sized reproduction therefore uses:

```text
dim                 = 128
stage               = 1
num_blocks          = [2, 1]
num_endmembers (K)  = 3
deformable_groups   = 8
attention_type      = full
```

This preserves the released encoder/bottleneck/decoder construction, matches the
paper's two-scale architecture in Fig. 3, makes the fixed 8 deformable groups
valid, and places the 3-channel RGB-reference model in the paper-reported ~5.94 M
parameter regime. `smoke_test.py` performs an explicit parameter-count audit and
fails before training if the reconstructed architecture leaves that regime.

**Provenance note.** The official GitHub repository does not commit the experiment
YAML used to instantiate UAFL, so `dim=128` is a parameter-count / architectural
reconstruction from the paper plus the released source, not a claim that an
unpublished YAML was directly read. This distinction is intentionally recorded
for reproducibility.

## Allowed channel adaptation

The paper uses a 3-channel HR RGB reference. The shared HSI-MSI benchmark changes
only the first reference projection:

```text
paper RGB:       Conv2d(3,   dim, 3, 1, 1)
PaviaU IKONOS:   Conv2d(4,   dim, 3, 1, 1)
Houston/Chikusei Conv2d(8,   dim, 3, 1, 1)
```

Everything after this reference input projection is unchanged.

The HSI spectral channel count does **not** need to be hard-coded. UAFL performs
SVD directly on the input HSI and reconstructs the output with the corresponding
endmember basis, so PaviaU 103-band HSI is naturally supported.

## Torch 2.6 / CUDA 12.4 compatibility

The released UAFL environment recommends old packages including PyTorch 1.10,
CUDA 11.3 and `mmcv_full==1.6.1`. Installing those binaries into the S2Diff
Torch-2.6/cu124 environment is intentionally avoided.

`dcn_compat.py` preserves the released DCNv2 weights, offsets, masks, deformable
groups and CFDA computation, while replacing only the backend call:

```text
mmcv.ops.modulated_deform_conv2d
        ->
torchvision.ops.deform_conv2d(..., mask=mask)
```

The deprecated `torch.svd` call is likewise replaced by the maintained equivalent
thin-SVD API:

```text
torch.svd(y)
        ->
torch.linalg.svd(y, full_matrices=False)
```

Neither change alters the UAFL learnable topology.

## Shared observation protocol

For the formal comparison, observations are generated by the repository-wide
shared code:

```text
GT-HSI                    fixed
  |-- shared LR degradation x4 --> LR-HSI fixed
  |-- sensor SRF ---------------> HR-MSI reference
```

UAFL, as in the paper, consumes an HSI already brought back to the HR grid:

```text
LR-HSI 16x16
  -> bicubic interpolation
  -> X_up 103x64x64
  -> UAFL
```

The HR-MSI remains 64x64. Under non-registration, **only HR-MSI is warped**;
GT-HSI and LR-HSI remain fixed. This matches the comparison benchmark's reference
frame and UAFL's unregistered-reference problem formulation.

PaviaU defaults:

```text
HSI bands      = 103
MSI sensor     = IKONOS
MSI bands      = 4
scale          = x4
HR train patch = 64x64
LR train patch = 16x16
stride         = 32
```

The shared `physical` degradation remains the default; `gaussian_bicubic` is also
available for diagnostic reproduction.

## Training settings

The launcher uses the paper training settings:

```text
optimizer     = AdamW
learning rate = 1e-5
weight decay  = 5e-5
batch size    = 1
loss          = L1
max epochs    = 300
```

Shared validation and early stopping are retained:

```text
PaviaU validation every 20 epochs
min_delta = 0.02 dB
patience  = 2 validation evaluations
validation deformation seed = 1234
best checkpoint = best.pth.tar
```

## 1. Strict smoke test

Run this before any training:

```bash
python comparison/UAFL/smoke_test.py
```

The smoke test checks:

- paper-interface parameter count against the 5.94 M regime;
- 103-band HSI + 4-band MSI forward;
- output shape `1 x 103 x 64 x 64`;
- finite L1 loss;
- finite backward gradients;
- finite CFDA prior flow and similarity;
- an exact 2-pixel HR-MSI translation;
- a 3-pixel smooth local HR-MSI deformation.

A healthy run ends with:

```text
UAFL smoke test: PASS
```

## 2. PaviaU registered sanity training

Do this first. It isolates fusion quality from non-registration robustness.

```bash
python comparison/UAFL/train.py \
  --dataset PaviaU \
  --degradation_mode physical \
  --train_misalignment_mode registered \
  --epochs 300
```

## 3. PaviaU formal HR-MSI non-registration training

After the registered baseline is healthy:

```bash
python comparison/UAFL/train.py \
  --dataset PaviaU \
  --degradation_mode physical \
  --train_misalignment_mode global_local \
  --translation_max_px 6 \
  --rotation_max_deg 3 \
  --local_max_displacement_px 3 \
  --control_grid_size 5 \
  --epochs 300
```

The formal validation reports both full-image metrics and valid-overlap metrics.
Model selection uses `PSNR_valid`.
