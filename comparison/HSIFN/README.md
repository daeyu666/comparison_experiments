# HSIFN reproduction for `comparison_experiments`

This folder contains the controlled-comparison reproduction of **HSIFN / HSI-RefSR** from:

> *Hyperspectral Image Super Resolution With Real Unaligned RGB Guidance*, IEEE Transactions on Neural Networks and Learning Systems.

Official source: `Zeqiang-Lai/HSI-RefSR`.

## Why this method fits this benchmark

The shared non-registration protocol in this repository fixes the HSI/GT coordinate frame and applies geometric misalignment **only to HR-MSI**. HSIFN has the same reference direction: it estimates dense flow from the HSI-side reference representation to the unregistered high-resolution reference image, warps that reference back to the HSI frame, and then fuses it into the HSI reconstruction.

That is different from methods whose registration module is hard-wired to warp LR-HSI toward the MSI frame.

## What is retained from the official HSIFN

`model.py` keeps the major published/released components:

1. **Coarse reference alignment** with the first FlowNet.
2. **Feature-level alignment** with a second FlowNet and four flow scales.
3. **Reference confidence masks** on the aligned feature pyramid.
4. **QRNN3D HSI encoder/decoder**, preserving spectral recurrence and spatial multi-scale fusion.
5. **SmoothL1 HSI reconstruction loss**, matching the official training module.
6. **AdamW** with the official real-unaligned defaults `lr=1e-5`, `weight_decay=5e-5`.

## HSI-MSI adaptation

The original implementation assumes RGB guidance. The controlled comparison uses sensor MSI:

- PaviaU: IKONOS 4 bands.
- Houston13: WorldView-2 8 bands.
- Chikusei: WorldView-2 8 bands.

The adaptation is limited to the reference input interface:

- both FlowNets accept dynamic `msi_channels`;
- the reference encoder accepts dynamic `msi_channels`;
- the HSI-side pseudo-MSI is produced with the **same SRF matrix used by the shared data loader**.

The registration direction remains:

```text
fixed LR-HSI / GT frame
        +
unregistered HR-MSI
        |
        v
HSI-side MSI proxy from SRF
        |
        +---- FlowNet 1 ----> coarse-aligned HR-MSI
                              |
                              +---- FlowNet 2 ----> multi-scale aligned MSI features
                                                    |
                                                    +---- masks
                                                          |
QRNN3D HSI encoder ---------------------------------------+
                                                          |
                                                     QRNN3D decoder
                                                          |
                                                      HR-HSI / GT frame
```

## Shared degradation and split

All observations are generated by the root `comparison_experiments` code. HSIFN does not carry a private data-degradation implementation.

Default controlled protocol:

- scale: `4x`;
- train HR patch: `64x64`, stride `32`;
- validation: fixed disjoint `128x128` region;
- test: fixed center `128x128` region;
- physical LR-HSI degradation: MTF Nyquist `0.2`, optical PSF, detector integration and x4 sampling;
- MSI generation: sensor SRF;
- valid-overlap metrics after MSI warp: `PSNR_valid` and `SAM_valid`;
- early stop: minimum improvement `0.02 dB`, patience `2` validations;
- PaviaU validation interval `20` epochs, Houston13 `10`, Chikusei `5`.

## Non-registration modes

The root shared operator `degradations/misalignment.py` is used without modification.

Available modes:

- `registered`
- `translation`
- `rotation`
- `global` = translation + rotation
- `local` = smooth non-rigid displacement
- `global_local` = translation + rotation + local non-rigid displacement

Only **HR-MSI** is warped. LR-HSI and GT stay fixed.

## Recommended first check

Before a full non-registration run, verify that the reproduction learns on registered observations:

```bash
python comparison/HSIFN/train.py \
  --dataset PaviaU \
  --degradation_mode physical \
  --train_misalignment_mode registered \
  --epochs 80
```

This is a diagnostic run, not the final non-registration comparison. It should clearly improve beyond the bicubic/LR-only regime. If registered training does not learn, do not continue to the deformation experiment.

## Full non-registration training

```bash
python comparison/HSIFN/train.py \
  --dataset PaviaU \
  --degradation_mode physical \
  --train_misalignment_mode global_local \
  --translation_max_px 6 \
  --rotation_max_deg 3 \
  --local_max_displacement_px 3 \
  --control_grid_size 5 \
  --epochs 300
```

For GPU memory pressure, enable AMP:

```bash
python comparison/HSIFN/train.py \
  --dataset PaviaU \
  --degradation_mode physical \
  --train_misalignment_mode global_local \
  --translation_max_px 6 \
  --rotation_max_deg 3 \
  --local_max_displacement_px 3 \
  --amp \
  --epochs 300
```

Checkpoints are isolated at:

```text
comparison/HSIFN/checkpoints/<degradation_mode>/<Dataset>/
```

The validation-selected checkpoint is:

```text
best.pth.tar
```

## Evaluation

Paired translation sensitivity curve:

```bash
python comparison/HSIFN/eval_misalignment.py \
  --dataset PaviaU \
  --degradation_mode physical \
  --protocol translation_sweep \
  --shifts 0 0.5 1 2 3 4 6 \
  --trials 5
```

Full scenario evaluation:

```bash
python comparison/HSIFN/eval_misalignment.py \
  --dataset PaviaU \
  --degradation_mode physical \
  --protocol full \
  --translation_max_px 6 \
  --rotation_max_deg 3 \
  --local_max_displacement_px 3 \
  --trials 5
```

Outputs are written under:

```text
comparison/HSIFN/outputs/<degradation_mode>/<Dataset>/
```

## Smoke test

The smoke test includes both forward and backward passes:

```bash
python comparison/HSIFN/smoke_test.py
```

It is intended to catch shape errors, broken gradients and accidental in-place autograd conflicts before a formal run.

## Reproduction note

This is a controlled-comparison adaptation rather than a byte-identical execution of the upstream repository. The HSIFN architecture and training objective are retained, while RGB-specific input assumptions are generalized to the exact MSI sensor channels/SRF used by this benchmark. This is necessary to compare all methods under the same PaviaU/Houston13/Chikusei observations and the same HR-MSI-only non-registration protocol.
